# Department directory

**Authoritative.** Each department keeps a convenience copy of the team map in its own
`knowledge/interop/ai-team.md`; where they differ, this file wins. When a scope, path or interface
changes here, the Management AI updates the departments in the same session (by sub-session).

**Identify a department by its repo path.** Display names drift; the path is the identifier.
