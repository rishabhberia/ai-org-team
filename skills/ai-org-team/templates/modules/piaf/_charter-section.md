## PIAF — Process Implementation & Assurance Framework

Whenever a new process, SOP, product feature, module or client implementation is designed, or an
existing one is materially changed, apply PIAF ({{MGMT_PATH}}/knowledge/group/piaf/PIAF.md): state
the Promise, Proof and Protection; cover the seven pillars scaled to criticality; name one
accountable Process Owner. Before a production release, check the Gate 1–3 evidence (§6); if any
is missing, list exactly what is missing and do not call the release PIAF-compliant. After
release keep Development Done → Implementation Done → Outcome Stabilized separate. The go-live
decision stays with the Process Owner and the approvers; no AI gains approval authority.
